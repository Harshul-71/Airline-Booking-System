# ✈️ Airline Booking System

A **Java console-based Airline Booking System** using **MySQL** for database management.

## 🚀 Features

* 👤 Customer Registration & Login
* ✈️ Domestic & International Flights
* 🔍 Flight Search
* 🎫 Flight Booking
* 💺 Seat Availability Management
* 📋 View & Cancel Bookings
* 📄 Download Ticket
* 🗺️ Destination Management
* 👨‍💼 Admin Management
* 🔐 Input Validation
* 🗄️ MySQL Database with Procedures & Triggers
* 🔗 Circular Linked List for DSA implementation

## 🛠️ Technologies

* Java
* MySQL
* JDBC
* SQL
* Data Structures & Algorithms

## 📁 Project Structure

```text
src/com/airline/
├── dao/
├── dsa/
├── models/
├── services/
├── util/
└── Main.java
```

## ⚙️ Setup

1. Install **Java JDK** and **MySQL**.
2. Create/configure MySQL connection in `DBConfig.java`.
3. Add the **MySQL Connector/J** library.
4. Run `Main.java`.
5. The application initializes the required database tables automatically.

## 🎯 Main Modules

**Admin:** Manage destinations, flights and bookings.

**Customer:** Register, login, search flights, book tickets, view bookings and cancel bookings.

## 📌 Note

This is a **console-based academic project** developed using Java, JDBC, MySQL and DSA concepts.
